# Process
At the beginning, I decided to make a line chart. I then used AI to source data and tried to generate a chart. I found that although the AI-generated chart included all required elements, it was hard to read. I looked up some references and asked AI to adjust colours and styles, so the line chart became readable and visually clean.

## Tools
I used Doubao AI to search for data, write code and help me learn tutorial materials. I also used Rednote for colour palette design, and for translating and polishing the README and PROCESS texts.

## Kept
I kept the topic selected by AI. I had no clear idea what phenomenon to visualise at first, so I asked AI to brainstorm several themes. I finally picked rainfall. This dataset is publicly available and easy to obtain; it would not be hard to source unlike niche datasets.

## Rejected
After choosing the topic, I rejected the original dataset recommended by AI. First, AI suggested rainfall records from the last century, which I thought were outdated and meaningless. Second, the dataset it provided was too small, containing only about ten days of readings. I asked it to use the latest two months of data instead. I also added markers for maximum and minimum values, improved the readability of date labels, kept all annotations within the chart boundary, and revised the title and layout to refine the final visualisation.
